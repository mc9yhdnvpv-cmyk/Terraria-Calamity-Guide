TERRARIA + CALAMITY COMPANION — iPHONE INSTALL

WHAT THIS VERSION DOES
- Tracks the intended vanilla + Calamity boss progression.
- Automatically surfaces the next unchecked boss.
- Tracks class, difficulty, world evil, loadout notes, permanent upgrades, and POIs.
- Links directly to the official Terraria wiki.gg and Calamity wiki.gg.
- Links to the live Calamity class-setup and progression pages so item advice can stay current.
- Stores progress locally on the device.
- Lets you export/import a JSON backup.
- Works as an installable PWA and caches the app shell for offline use.

HOW TO INSTALL ON IPHONE
1. Upload the CONTENTS of this folder to an HTTPS static host.
   Recommended easy options: GitHub Pages, Netlify, Cloudflare Pages.
2. Open the resulting HTTPS site in Safari on the iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Make sure “Open as Web App” is enabled if iOS shows that option.
6. Tap Add.
7. Launch Terraria Guide from the Home Screen.

IMPORTANT
- The app itself works offline after it has been opened once.
- Wiki pages still require an internet connection.
- Safari/local storage contains your progress. Use Settings > Export save backup occasionally if the playthrough matters to you.
